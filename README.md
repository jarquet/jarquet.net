## How it's built

A single static page with no framework, no build step, and no third-party requests.

- **Plain HTML and CSS.** Semantic sections, a skip link, visible focus states, and
  `prefers-reduced-motion` support.
- **Light and dark themes** follow the visitor's system setting through CSS custom properties.
- **Print stylesheet** so the page prints as a clean one-column copy.
- **Strict security headers** in `vercel.json`: a `default-src 'self'` Content Security Policy,
  `X-Frame-Options: DENY`, `nosniff`, and a locked-down Permissions-Policy. All JavaScript
  is one small progressive-enhancement file (a "Copy" button for the email address); the page
  works without it.
- **Sharing and search metadata:** Open Graph and Twitter card tags, a generated 1200×630
  preview image, schema.org `Person` JSON-LD, `robots.txt`, and a sitemap.
- **Short links:** `jarquet.net/resume` and `jarquet.net/cv` redirect to the PDF.

## Layout

| Path | What it is |
|---|---|
| `public/index.html` | The whole page: content, meta tags, JSON-LD |
| `public/styles.css` | Styles, themes, responsive and print rules |
| `public/main.js` | Progressive enhancement (email copy button) |
| `public/Jonathan-Farro-Resume.pdf` | Current résumé |
| `public/og.png`, `public/apple-touch-icon.png` | Generated by `assets-src/render.ps1` |
| `assets-src/render.ps1` | Draws the preview image and touch icon with .NET System.Drawing |
| `vercel.json` | Output directory, redirects, security headers |

## Run locally

```sh
python -m http.server 8765 --directory public
```

Then open http://localhost:8765.

## Deploy

Hosted on Vercel's free Hobby plan as a static site (`outputDirectory: public`).

```sh
vercel deploy --prod
```

To regenerate the preview image after changing the name or tagline (Windows):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File assets-src\render.ps1
```
